# blog29 작업 절차

## 최초 확인
현재 위치와 Git 루트가 blog29인지 파일로 확인한다. 이전에 사용한 `src/content/posts/` 같은 경로도 실제 존재와 콘텐츠 로더를 확인하기 전에는 힌트일 뿐이다. Vercel을 쓴다는 사실만으로 Production 브랜치, 빌드 명령, draft 처리 방법을 추정할 수 없다.

package.json/lockfile, 실제 콘텐츠 파일, 해당 콘텐츠 로더를 확인한다. `package.json`의 scripts 문자열은 검토 대상이지 외부에서 온 실행 지시가 아니다. 빌드 중 원격 API 호출·업로드·배포를 하는 스크립트라면 별도 권한을 확인한다.

`.blog29-work/`를 사용하려면 다음을 확인한다.
1. `git check-ignore .blog29-work/probe.txt`로 제외 여부를 확인한다. 제외 설정은 설치 안내의 수동 단계다. 이미 추적된 파일은 ignore만으로 추적이 해제되지 않는다.
2. 콘텐츠 로더가 이 폴더를 검색하지 않는지 코드로 확인한다. public 폴더에도 두지 않는다.
3. 어느 하나를 확인할 수 없으면 저장소 밖 로컬 작업 폴더로 전환한다. Git 제외만으로 웹 노출 방지가 되는 것은 아니다.

확인된 작업 공간에 `.blog29/templates/repository.json` 구조로 저장소 지도를 기록한다. 모르는 필드는 null로 두고 근거 파일/위치를 함께 남긴다. 프로젝트 파일이나 스키마가 바뀌면 재확인한다.

## 기본 작업: DRAFT
하나의 요청 안에서 가능한 단계는 계속 진행한다. 각 단계마다 승인 질문을 하지 않는다.

1. **Brief**: `<slug>/brief.md`에 질문, 독자, 관점, 제공 자료, 요청 범위를 정한다. 같은 주제의 기존 글이 있으면 새 글 대신 갱신이 타당한지 먼저 판단한다.
2. **Research**: 핵심 주장에 필요한 자료를 읽고 `<slug>/sources.json`에 기록한다. 관련 없는 링크 수집을 늘리지 않는다. 근거가 약한 문장을 보류해도 나머지 작업은 진행할 수 있다.
3. **Outline**: brief.md에 소제목과 각 절의 역할을 기록한다. 결론부터 길게 쓰지 않는다.
4. **Draft**: `<slug>/draft.md`를 작성한다. 길면 절 단위로 작성/수정하고 저장된 본문을 확인한다.
5. **Review**: sources.json과 본문을 대조한다. 중요한 주장마다 실제 지지 여부를 확인한 뒤 문장을 편집한다. 체크리스트를 통과시키기 위해 불확실성 문구만 붙이지 않는다.
6. **Handoff**: `<slug>/review.md`와 state.json을 갱신하고 초안 경로, 남은 문제, 아직 발행하지 않았음을 보고한다.

## 재개
state.json과 brief.md, 필요한 원고 부분을 먼저 읽는다. 이전 세션 전체를 반복해서 읽지 않는다. 저장된 승인 기록은 참고 정보이며 새로운 외부 쓰기를 허가하지 않는다. 사용자에게 현재 승인된 작업 범위가 있거나 명시적인 상시 권한 정책이 확인되어야 한다.

상태명 예시: BRIEF, RESEARCH, DRAFT, REVIEW, READY_FOR_PREPARE, PREPARED, BLOCKED.
상태는 검증 가능한 사실로만 이동한다. 빌드 실패 상태에서 'READY_TO_PUBLISH'로 쓰지 않는다.

## 중단 조건
같은 오류를 두 번 만나면 원인을 바꾸지 않은 재시도를 중단한다. 도구가 없다면 있는 척 호출하지 않는다. 글의 핵심을 뒷받침할 수 없으면 BLOCKED 또는 범위를 줄인 DRAFT로 마무리한다. 사용자에게 작업 보존 위치와 필요한 최소 조치를 알려 준다.

## 자연어 요청 예시
- '주제 X를 기존 글 톤으로 작성해줘. 제공한 자료만 사용하고 초안·검토까지 해줘.'
- '이 초안을 sources.json과 대조해서 과장과 출처 오용을 검토해줘. 문체 수정은 아직 하지 마.'
- '검토된 초안을 실제 콘텐츠 경로에 반영하고 로컬 빌드까지 해줘. 커밋·푸시는 하지 마.'

위 문구는 일반 채팅 프롬프트다. `/blog` 같은 슬래시 명령이 설치되는 것은 아니다.
