# Welcome to Blog29

This is my new personal blog built with **Next.js**, **MDX**, and **Tailwind CSS**.

## How to write a post

1. Create a new `.mdx` file in `src/content/posts/`
2. Add frontmatter metadata (title, date, excerpt)
3. Write your content in Markdown or JSX
4. `git push` and let Vercel handle the deployment!
