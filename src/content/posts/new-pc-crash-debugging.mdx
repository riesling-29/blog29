산 지 얼마 안 된 PC가 갑자기 멈추거나 혼자 재부팅됐다. 이벤트 뷰어나 덤프 파일 같은 말은 몰라도 되는 상황이었으면 했다. 그래서 Grok Bot에게 아는 만큼만 물어봤다.

## 질문은 이게 전부였다

> 내 컴퓨터 사용 가능해?
>
> 산 지 얼마 안 됐는데 갑자기 멈추고 그래서 뭐가 문제인지 궁금하거든

증상을 어떻게 설명해야 하는지도, 어디부터 봐야 하는지도 말하지 않았다. Grok Bot은 이 두 문장을 "멈춤의 원인을 찾아 달라"는 요청으로 알아듣고 바로 시스템 사양과 이벤트 로그부터 열었다. 명령을 실행할 때마다 승인을 받고 진행했다.

## 로그를 대신 읽어 줬다

첫 보고는 이랬다.

> 블루스크린이 2번, 절전 중에 멈춘 게 여러 번 있었어요. CPU·디스크·램 하드웨어 오류는 없어요. 정확한 원인을 보려면 충돌 기록을 분석해야 하는데, 분석 도구(WinDbg)를 설치할까요?

내 대답은 "응" 한 글자였다. Grok Bot은 WinDbg를 설치하고 충돌 덤프 두 개를 분석했다.

> 원인 찾았어요. 10/28은 NVIDIA 그래픽 드라이버(`nvlddmkm.sys`), 오늘은 와이파이 드라이버(`nwifi.sys`) 때문이었어요. 하드웨어 고장은 아니에요.

로그를 더 보니 멈춤은 대부분 절전으로 들어가는 중에 났고, 빠른 시작이 실패한 기록도 있었다. 드라이버 문제에 빠른 시작과 절전 전환이 겹친 것으로 보인다는 게 Grok Bot의 판단이었다. 확정이 아니라 추정이라는 점도 같이 말해 줬다.

## 설치도 알아서 했다

> 드라이버 설치 좀 해줘. 그리고 빠른 시작은 어디서 끄지?

어떤 드라이버를 어디서 받는지는 묻지 않았다. Grok Bot은 메인보드 제조사(ASUS) 공식 경로에서 와이파이 드라이버를, NVIDIA 공식 경로에서 그래픽 드라이버(621.01)를 받았다. 설치 전에는 파일 해시와 서명이 맞는지 확인했다.

빠른 시작은 설명대로 찾아가도 메뉴가 없었다.

> 니가 말하는 빠른 시작 끄기 메뉴가 안 보이는데?
>
> 최신 윈도우 11에서는 숨겨진 경우가 있어요. 제가 바로 꺼 드릴게요.

메뉴를 찾느라 헤맬 필요 없이, Grok Bot이 레지스트리 값(`HiberbootEnabled`)을 직접 바꾸고 다시 읽어 꺼진 것까지 확인했다.

## 사운드바도 덤으로

블루투스 사운드바 소리가 가끔 끊기던 문제도 같이 봤다. Grok Bot은 블루투스 어댑터가 두 개 잡혀 있는 걸 찾아냈다. 메인보드 내장 어댑터와 예전에 꽂아 둔 USB 동글이 충돌하고 있었고, 로그에도 "하나의 활성 블루투스 어댑터만 지원"한다는 기록이 여러 번 남아 있었다. 동글은 끄고, 내장 블루투스는 절전을 끈 뒤 공식 드라이버로 바꿨다.

## 정리하면

내가 한 일은 증상을 말하고, "응"이라고 답하고, 메뉴가 안 보인다고 말한 것뿐이다. 나머지는 Grok Bot이 했다.

- 이벤트 로그와 충돌 덤프 분석
- 원인 드라이버 특정, 하드웨어 고장 배제
- 공식 드라이버 다운로드, 해시·서명 확인, 설치
- 숨겨진 설정 변경과 결과 확인

바뀐 값은 모두 명령으로 다시 읽어 확인했다. 다만 재부팅 뒤에 계속 안정적인지는 며칠 더 지켜봐야 한다.

<summary>기술 메모</summary>

- 사양: Windows 11 Pro, Ryzen 7 9800X3D, ASUS B850M MAX GAMING WIFI, RTX 5070 Ti, DDR5-5600 16GB×2
- 덤프: 10/28 버그체크 `0xA`(`nvlddmkm.sys`), 11/04 버그체크 `0x13A`(`nwifi.sys`). WinDbg `cdb`의 `!analyze -v`로 분석
- 로그: Kernel-Power 41 반복(주로 `SleepInProgress=6`), 빠른 시작 실패 3회, WHEA 오류 없음
- 와이파이: Realtek 8851BE 6001.19.138.0, `pnputil /add-driver netrtwlane603.inf /install`
- 그래픽: NVIDIA 621.01(드라이버 버전 32.0.16.2101), `-s -clean -noreboot`로 설치
- 빠른 시작: `HKLM\SYSTEM\CurrentControlSet\Control\Session Manager\Power`의 `HiberbootEnabled=0`
- 블루투스: USB 동글 `Disable-PnpDevice`, 내장 어댑터 `MSPower_DeviceEnable=False`, ASUS 드라이버 18.4049.2505.2300
